A Meteor Addon made for 2b2t.xin(Running on Minecraft 1.21.11).
| 模块名 | 作用 |
|---|---|
| AutoArmor+ | 自动从背包装备最优护甲 |
| AutoEZ | 自动嘲讽,播报图腾被破、玩家断线等事件 |
| BlockLag | 卡黑曜石+|
| BowBomb | 欺骗移动包让蓄力弓射击变成爆炸 |
| Burrow+ | 卡黑曜石|
| CrystalHurtPeople | 光速水晶|
| ElytraFly+ | 鞘翅飞行控制，支持 Control / Pitch / Freeze / Rotation 等模式 |
| FakePlayer+ | 客户端生成假人，支持攻击/爆炸伤害模拟、自动图腾、死亡重生（暂时用不了） |
| FlatGroundMace | 平地锤 |
| Mace32K | 核弹锤 |
| MaceAura | 重锤光环，提供各种锤法|
| MaceGodPlus | 虚空锤，没试过有没有用 |
| MacePlus | 风弹锤 |
| MaceSpoof | 欺骗移动包以扩大 mace 攻击距离 |
| MaceSpoof2 | Forever 版 mace spoof 实现 |
| Offhand+ | 副手物品 |
| Skybox | 自定义天空盒纹理 |


ps:AI打滑客户端，BUG一堆很正常,后面会加一些原创功能
